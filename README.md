# Smart Emergency Rescue System (Detect Falling Down)

Hệ thống phát hiện té ngã và cảnh báo khẩn cấp tự động ứng dụng Trí tuệ Nhân tạo (Computer Vision & AI Pose) kết hợp thiết bị IoT (ESP32).

## Tính năng chính
- **AI Pose Detection**: Tự động nhận diện tư thế và phát hiện sự cố té ngã theo thời gian thực (YOLO Pose / MediaPipe).
- **Phân tích hành vi**: Xác định góc cơ thể, tốc độ thay đổi vị trí và thời gian bất động để giảm báo động giả.
- **Tích hợp IoT (ESP32)**: Cảnh báo qua loa, còi và kết nối điều khiển/giám sát từ xa.
- **Web Demo Interface**: Giao diện điều khiển và trực quan hóa dữ liệu qua Web.
